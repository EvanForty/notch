# NOTCH — The Floor-Raising Launchpad

Concept prototype for NOTCH, a Solana launchpad where every token launches with a reserve-backed price floor that steps up ("notches") as trading fees fill the reserve.

All tokens, traders and trades on the site are simulated in the browser. Nothing connects to a wallet or a blockchain.

X: https://x.com/NotchPadDotFun

## Files

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `favicon.svg` — the NOTCH logo
- `vercel.json` — Vercel settings

## Deploy on Vercel

1. Push these files to the root of a GitHub repo.
2. In Vercel, choose **Add New → Project** and import the repo.
3. Framework preset: **Other**. Leave build command and output directory empty.
4. Deploy.

## Run locally

Open `index.html` in a browser, or run `npx serve .` in this folder.
